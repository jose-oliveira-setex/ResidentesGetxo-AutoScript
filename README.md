Este programa tiene un buzón de correo asociado, recibe correos todos los días con los residentes de Getxo, y se encarga luego de descargarlo y subirlo a una carpeta dentro del servidor. Y ya luego otro script se encarga de meter el txt en la base de datos.

Se debe colocar la información de los tokens de Microsoft para poder acceder a los correos, que no se coloco en el archivo por seguridad.

Una vez colocado este archivo en el servidor se debe programar las tareas programadas con windows.
